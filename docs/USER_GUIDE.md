# Rhythm Editor 改良功能使用说明

本文说明 `RhythmEditorMod` 当前增加的功能。所有操作只修改 working / 已安装插件的副本；`RhythmEditor_original` 不受影响。

## 启动与面板

日常使用正式安装包时，从 `RhythmEditor_modded/` 启动 `Rizline Editor.exe`。开发验收从 `RhythmEditor_working/` 启动。按 `F8` 显示或隐藏插件面板。

首次安装或更新时，把完整 `RhythmEditorMod/` 文件夹放到编辑器根目录并双击其中的 `RhythmEditorMod.Manager.exe`。详见 `docs/DISTRIBUTION.md`。

### 各工具显示的插件内容

| 工具 | 面板内容 |
| --- | --- |
| 光标 | 基础设置：突破缩放极限；预览细线；**预览蒙版**；面板宽度滑条；面板透明度滑条 |
| 音符编辑 | 无 |
| 画线 | 一键加入调色板；线剪贴板导出/导入 |
| 颜色编辑 | 一键加入调色板；颜色事件框选剪贴板 |
| 主题编辑 | 一键加入调色板 |
| 画布流速 | 缓动采样；流速剪贴板 |
| 画布移动 | 画布事件剪贴板 |
| 摄像机移动 | 摄像机移动剪贴板 |
| 发布 | 谱面统计（画布数、线数、Tap / Hold / Drag） |
| 项目 | 最近三个工程（谱面 + 音乐），点击即切换；「选择文件…」走原版两步对话框（该工具用的是原生 body 面板，不受 `F8` 控制，选中即显示） |
| 其他 | 无面板（F8 显示状态仍记住，但当前无内容） |

## 项目：编辑器内切换工程

工具栏最后一个按钮「**项目**」（快捷键 `9`）。选中后工具栏旁出现原生样式的面板：

- **三个槽位**：最近打开过的工程（谱面 + 音乐），当前工程带 `▶`。点击槽位**直接切换**，不需要退出重进。
- **选择文件…**：调用原版的两步对话框（先谱面、再音乐）；打开后该工程会自动进入槽位。
- **切换前会自动保存**：当前谱面若有未保存改动，先按原版方式保存再切换；若是从未保存过的**新工程**（没有谱面路径），会**拒绝切换并提示**，请先 `Ctrl+Shift+S` 另存为。
- **状态行**：显示「已打开：<谱面文件> + <音乐文件>」或失败原因。
- 槽位记录在 `BepInEx/config/RhythmEditorMod/projects.json`，可自行查看/备份。
- 切换时会清掉上一次遗留的音乐缓存临时文件（仅限系统临时目录下、扩展名 `.tmp` 且与当前缓存不同的那个）。

面板的位置和大小可以自己调：改 `BepInEx/config/RhythmEditorMod/layout.json`（面板尺寸、偏移、行高、标题框宽度与留白、标签字数上限等），**重启编辑器**生效；日志会打印实际生效值，写错的键名会有告警。

注意：该面板**只在选中「项目」工具时显示，不会跟随鼠标**；切换到其它工具才隐藏。

## 光标：基础设置

选中**光标**后按 `F8` 可见：

- **突破缩放极限**（默认关）：打开后 Ctrl+滚轮音符流速可到 -0.5；并允许 `Ctrl+Shift+滚轮` **整体缩放 40%–200%**（放大与缩小共用这个开关）。关闭后下限回到 0.1，缩放复位到 100%。
- **预览细线**：带预览的播放期间把谱面线宽缩到约 75%，退出预览或关闭开关后恢复。
- **预览蒙版**（默认**开**）：**开**＝完全按原版显示（零干预）。切到**关**后，**带预览的播放**期间会隐藏编辑器界面上的深灰覆盖层与游戏中遮住四周的遮挡块，**背景色与其它内容照原样保留**，被挡住的谱面因此可见；停止播放后恢复原版，或播放中直接拨回**开**也会立刻恢复。无预览播放不受影响。
- **游玩区域边框**：`预览蒙版：关` 且带预览播放时（或整体缩放不为 100% 时）自动出现，用 **2px** 边框标出「原本未被遮住、游玩时实际可见」的区域。颜色取自谱面主题的 **UI 色**（`themes[*].colorsList[2]`），所以 Riztime 段会自动变色。边框不随播放移动、不受流速影响，随整体缩放与窗口变化，**线宽恒为 2px**。
- **面板宽度 / 透明度**：自绘滑条，只影响插件 IMGUI 窗口。

### 音符流速与整体缩放

- Ctrl+滚轮调的是界面上的**音符流速**，不是摄像机缩放。默认最低 0.1；突破极限开启后可为 0.0、-0.1…直到 -0.5。显示到 0.0 及更低时，普通滚轮会逐步加快。
- 突破极限开启后，`Ctrl+Shift+滚轮` **整体缩放**（横竖同比例），范围 **40%–200%**、**每格 10 个百分点**（40、50、…、100、110、…、200；向上滚放大、向下滚缩小，不能超过两端）。右上角显示 `缩放 N%`。`Ctrl+M` 随时复位到 100%。
- 缩放通过改写相机投影矩阵实现，因此原版 UI 画布需要临时改为 Overlay 才能保持可见——代价是**缩小时部分 UI 可能点不到**（已知问题，未处理）；复位到 100% 即恢复正常。

## 线编辑：跨画布线的复制 / 粘贴

一条线的节点可以分布在多个画布上（形状不固定），原版无法框选、粘贴也会把所有点压到当前画布。用法：

1. 进入**线编辑**并先点一下画布 → 按 `Ctrl+C`（或 `Ctrl+X`）→ 拖出矩形框，**拖的时候按住 `Shift`**。
   - 只有**当前画布**上被**完全框住**的节点才会命中，命中即**整条线**（含它在其它画布上的节点）入选；
   - 拖动过程中选中的线会**实时高亮**（用原版的复制色），松开鼠标高亮结束；
   - 不按 `Shift` 时行为与原版完全一致（不会高亮，也不会整条选）。
2. `Ctrl+V` 粘贴：整条线按**鼠标位置**对齐（拍吸附跟随垂直细分，x 吸附跟随**水平细分**），并且**每个节点的画布整体偏移**——偏移量 = 粘贴时所在画布 − 复制时所在画布（例如复制时在画布 2、粘贴时在画布 4，则节点画布 1→3、2→4、3→5）。若偏移后出现谱面中不存在的画布，会**放弃粘贴并提示**。
3. `Ctrl+Shift+V` 为**镜像粘贴**：以鼠标为对称轴左右翻转。
4. 一次粘贴 = 一步 Undo；`Esc` 或离开线编辑工具会取消高亮。
5. **剪贴板归属**：谁最后复制谁生效——Shift 复制后再用原版 `Ctrl+C`，`Ctrl+V` 粘的就是原版那份（反之亦然）。

注意：`Shift` 剪切目前按复制处理（不删除原线）。
## 发布：谱面统计

选中**发布**时，面板只显示当前谱面统计：画布数量、线数量、Tap / Hold / Drag 数量（及若有其他类型音符）。光标等其它工具不会出现该统计。

## 框选删除（Ctrl+D）

在画布流速、画布移动、颜色、摄像机等支持框选的标签下，以及画线工具下：

- `Ctrl+X`：剪切（内容进入软件剪贴板；行为与原先一致）。
- `Ctrl+D`：框选后**只删除**，不把内容写入软件剪贴板（删除前剪贴板内容保持不变）。画线工具下复用原版 `CutLines` 后还原线剪贴板。

每次启动后首次框选前，仍需先进入一次「线编辑」标签以初始化原框选组件。

## 流速缓动离散采样

进入「画布流速」标签：

1. 设置垂直细分（如 `1/4`、`1/16`）；生成间隔直接使用该值。
2. 把播放头移到已有流速节点上，点「记录起点」；再移到更晚的节点，点「记录终点」。
3. 选择缓动（默认 `Linear`；点击名称展开/收起下拉，选项与原版一致，如 `Out Quad`）。
4. 查看预计节点数后「生成并替换区间」。端点保留，内部替换为离散采样；终点即使不在网格上也会保留。

预计超过 4096 个节点会警告，可继续或取消。整次生成是一个 Undo/Redo 步骤。JSON 仍只含普通 `speedKeyPoints`。插件会跳过因 float 精度塌缩到端点拍的内部采样，避免同一拍出现两个速度事件。

## 弹性缓动（`In` / `Out` / `InOut Elastic`）

原编辑器的缓动表固定 19 条，且 `easeType ≥ 19` 会直接报错；游戏也只认这 19 种。因此插件新增的弹性曲线不是新的缓动类型，而是**把曲线烘焙成一批普通的 Linear 节点**写进谱面——游戏播放时看到的仍是它认识的缓动。

**支持范围：编辑画布、编辑摄像机·横向移动。**

用法（以画布为例）：进入「**编辑画布**」标签 → 把**播放头移到目标区间内**（起点到下一个画布事件之间）→ 展开缓动下拉框，末尾三项即 `In Elastic`、`Out Elastic`、`InOut Elastic`，选中即生效。「编辑摄像机」同理，但请先确认当前编辑的是**横向移动**：

- `In Elastic`：先反向蓄力，再猛冲到目标值；
- `Out Elastic`：先冲过目标值，再回落收敛；
- `InOut Elastic`：前半段反向蓄力、过中点后过冲收敛。

**不支持的两处**（均保持原版行为）：

- **摄像机缩放**：在下拉里选插件曲线只会提示不支持，**谱面不会有任何改动**（此前曾支持，因出现越界异常由使用者取消）。
- **编辑线**：下拉框里没有这三项，线工具完全保持原版——它靠拖动创建线、`Ctrl`+拖动改节点属性，插件不做介入。

说明：

- 曲线整体按该区间**首尾差值**缩放，所以**首尾数值相同的区间不会产生任何节点**（插件只提示）；想要「原地抖动」需要另加绝对幅度方案。
- 节点位置按**曲线弯曲程度自动分布**（弯曲处密、平坦处稀），不与拍线网格对齐；默认容差下 2 拍区间约 21–25 个内部节点，节点数超过 4096 会提示。
- 整段拟合只占**一个 Undo 步骤**（`Ctrl+Z` 一次整体撤销）；它会替换该区间原有的中间节点并把起点缓动改为 Linear。
- 选择插件曲线后下拉框会**自动回到 `Linear`**，这是正常的：曲线已经写进节点里，显示与数据保持一致。
- 若某个节点里存在越界的缓动值（例如被早期版本写坏），插件会**按 Linear 求值并告警**而不会崩溃；把该段 `Ctrl+Z` 撤销、或重新选一次 `Linear` 即可恢复。

## 流速复制、剪切与粘贴

- `Ctrl+C` / `Ctrl+X`：拖出矩形框选（只看上下端拍数）。
- `Ctrl+V`：当前画布按原拍粘贴。
- `Ctrl+Shift+V`：最早节点对齐播放头。
- `Ctrl+D`：删除选区，不进剪贴板。

剪切时画布首个流速节点只复制不删除。粘贴覆盖同拍旧节点。流速与画布事件使用独立剪贴板。

## 画布事件复制、剪切与粘贴

进入「画布编辑」：

- `Ctrl+V`：最早事件的横坐标和拍数对齐鼠标，其余按相同偏移平移。
- `Ctrl+Shift+V`：同样对齐鼠标，并左右镜像横向相对偏移。
- 拍数与横坐标会按垂直/水平细分吸附。首个画布事件剪切时只复制不删除。

## 系统剪切板

流速、画布事件、颜色、摄像机、线等面板底部：

- **导出到剪切板**：开关，默认关。打开后，复制/剪切在更新内部剪贴板的同时写入 Windows 剪切板。
- **从剪切板导入**：手动点击；只替换对应内部剪贴板，不立刻改谱面。不同种类头部不同，不能混用。

文本以 `rzemod-clipboard … 1` 开头；字段空格分隔，也接受制表符。

## 线色、判定环与摄像机

- **颜色编辑**：`Ctrl+C/X` 后拖动框选，并先聚焦一个画布（没有聚焦画布时原编辑器不会显示框选矩形）。
  - 拍数范围只看框选的上下端；**横向位置决定取哪一类**：

    | 框选矩形 | 取的内容 |
    | --- | --- |
    | 整个在大地 x=0 **左侧** | 只取**线色覆盖** |
    | 整个在大地 x=0 **右侧** | 只取**判定环** |
    | **跨过** x=0 | 两类都取 |

  - `Ctrl+V` 粘贴上次复制的内容并**保持原拍数**；`Ctrl+Shift+V` 把最早事件**对齐播放头**。
  - 粘贴哪个数组跟随"上一次真正复制到内容的那次复制"，不再看当前停在哪个颜色页签。
  - 目标拍上已有事件时**覆盖**它；同拍重复会被合并成一条，数组其余顺序不重排。
- **摄像机编辑**：只框选移动，不框选缩放。粘贴规则同画布移动（覆盖同拍）。

点插件面板时，该次点击不会在谱面落线。

## 画线与调色板

画线仍用原版复制、剪切、粘贴。打开「导出到剪切板」后，原版复制/剪切会把线写成系统文本（`rzemod-clipboard lines 1`）。「从剪切板导入」只替换内部线剪贴板。

「一键加入调色板」（画线 / 颜色 / 主题）：

- 收集主题色、线基础色、`lineColor` / `judgeRingColor` 起止色，去重后写入 `ProjectInformation.colorPanels` 与 `colorPanels*`；
- 只填白色空槽，不覆盖已有色。

## 保存与兼容性

仍用原编辑器 `Ctrl+S` / `Ctrl+Shift+S`。插件不增加自定义 JSON 字段；流速位置由原 `EditControl.SetFloorPosition` 重算。建议先在测试谱面用 Undo/Redo 检查再保存正式谱面。

## 禁用、启用与重新构建

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Set-RhythmEditorModEnabled.ps1 -Mode Disable
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Set-RhythmEditorModEnabled.ps1 -Mode Enable
```

操作前先退出编辑器。禁用不会还原已写入 JSON 的普通流速节点。

主要代码：`src/RhythmEditorMod/`（面板与热键）、`src/RhythmEditorMod.Core/`（纯数据）、`tests/RhythmEditorMod.Core.Tests/`。修改后退出编辑器再运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Build-Install-RhythmEditorMod.ps1
```

预期测试全部通过、0 错误，并显示安装路径。异常时提供终端输出或 `BepInEx/LogOutput.log` 末尾。
